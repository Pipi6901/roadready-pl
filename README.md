# RoadReady

Кросс-платформенное приложение для подготовки к экзамену по теории вождения. Формат Duolingo: короткие уроки, мгновенная обратная связь, XP и серия дней. Ключевое отличие от конкурентов — вопросы показываются на английском **и на выбранном пользователем языке** одновременно, а страна и язык заложены как две независимые оси.

Первый рынок — Великобритания, 9 языков перевода. Архитектура рассчитана на добавление новых стран без релиза приложения.

Стек: Expo SDK 57 (React Native 0.86, New Architecture), expo-router, TypeScript strict.

## Быстрый старт

Нужен Node 20.19.4 или новее (проверялось на 22.x) и npm.

```bash
git clone https://github.com/alexander0999/roadready.git
cd roadready
npm install
```

### Посмотреть в браузере — самый быстрый способ

```bash
npx expo start --web
```

Откроется `http://localhost:8081`. Приложение свёрстано под мобильный экран, поэтому включите в devtools режим устройства (⌘⇧M в Chrome) и поставьте что-нибудь вроде iPhone 12 — иначе увидите растянутый на весь монитор макет.

**Тёмная тема** переключается системной настройкой ОС либо в devtools: Rendering → Emulate CSS media feature prefers-color-scheme.

Веб-режим — только для быстрого просмотра вёрстки и логики. Целевые платформы iOS и Android; часть нативного (тактильная отдача, видео, TTS) в браузере работает частично или не работает.

### Посмотреть на телефоне

```bash
npm start
```

Отсканировать QR приложением Expo Go. Нативных модулей вне Expo SDK в проекте пока нет, так что dev-build не требуется.

### Проверки

```bash
npm run typecheck   # tsc --noEmit, должен быть пустой вывод
npm run lint
```

## Как обойти экраны

Онбординг и пейволл **выключены флагами** (подключаются через Adapty позже), поэтому приложение стартует сразу с главной. Экраны никуда не делись — открываются по прямым ссылкам.

| Экран | URL |
|---|---|
| Splash | `/` (сразу редиректит на главную) |
| Welcome | `/welcome` |
| Выбор страны | `/country` |
| Выбор языка | `/language` |
| Дата экзамена | `/goal` |
| Пейволл | `/paywall` |
| **Главная** | `/` (после редиректа) |
| Карта тем | `/learn` |
| Практика | `/practice` |
| Профиль | `/profile` |
| Тема | `/topic/road-signs` |
| Урок | `/lesson/road-signs` |
| Итоги урока | `/lesson/complete?topicId=road-signs&total=5&correct=4&xp=40` (без параметров покажет нули) |
| Мок-тест | `/mock/setup` → `/mock/run` → `/mock/review` → `/mock/results` |
| Быстрый тест | `/quiz` |
| Работа над ошибками | `/weak-spots` |
| Hazard Perception | `/hazard/1` (за флагом, покажет «Coming soon») |
| Настройки | `/settings`, `/settings/subscription` |
| Смена страны / языка | `/change-country`, `/change-language` |
| Окончание триала | `/trial-ended` |
| Достижение | `/achievement?id=first-lesson` |

Идентификаторы тем: `road-signs`, `junctions`, `motorways`, `hazard-awareness`, `vehicle-safety`, `rules-of-the-road` и далее по списку в `src/data/demo-bundle.ts`.

### Что стоит посмотреть в первую очередь

1. **Двуязычный режим** — ради него всё и затевалось. Откройте `/change-language`, выберите Español или Polski, затем `/lesson/road-signs`: английский сверху крупнее, перевод под ним мельче. Переводы есть только для этих двух языков — остальные семь придут с бэкенда.
2. **Урок целиком** — ответьте верно и неверно, посмотрите на панель обратной связи и начисление XP.
3. **Мок-тест** — таймер, флажки, сетка проверки перед отправкой, результаты с разбивкой по темам.
4. **Карта тем** `/learn` — последовательная разблокировка, пройдите первый урок и посмотрите, как откроется вторая тема.
5. **Тёмная тема** на любом из экранов.

### Сброс состояния

Прогресс, настройки и подписка лежат в localStorage. Чтобы начать с чистого листа — в консоли браузера:

```js
localStorage.clear(); location.reload();
```

На устройстве — Settings → Reset progress.

### Включить онбординг и пейволл

Один файл — `src/constants/flags.ts`, поменять `false` на `true`. Все следствия расписаны в [11-feature-flags.md](docs/11-feature-flags.md).

## Что внутри

```
app/            маршруты Expo Router — только композиция экранов
src/
  theme/        токены и провайдер темы
  components/   ui/ — примитивы, остальное по областям
  store/        провайдеры: настройки, прогресс, контент, подписка
  features/     логика сценариев
  constants/    продуктовые правила и фича-флаги
  data/         демо-банк вопросов
  types/        модель контента
docs/           документация проекта
docs/design-specs/   полное дерево узлов каждого экрана из макета
```

Контент сейчас — демо-банк: 48 собственных вопросов по Highway Code, 14 тем, переводы на испанский и польский. Реального банка DVSA в репозитории нет и быть не может до подписания лицензии.

## Три вещи, которые важнее остального

1. **Лицензия DVSA блокирует релиз, а не разработку.** Заявка подаётся в первую неделю, разработка идёт на демо-банке. Публиковать вопросы DVSA без договора — уголовное правонарушение.
2. **Страна и язык — независимые оси.** Если добавление Ирландии потребует правок в коде приложения, архитектура сделана неправильно. Параметры экзамена (50 вопросов / 57 минут / проходной 43) — данные страны, а не константы.
3. **Аккаунтов нет.** Прогресс живёт на устройстве, подписка возвращается через Restore Purchase.
