# RoadReady

Кросс-платформенное приложение для подготовки к экзамену по теории вождения. Формат Duolingo: короткие уроки, мгновенная обратная связь, XP и серия дней. Ключевое отличие от конкурентов — вопросы показываются на английском **и на выбранном пользователем языке** одновременно, а страна и язык заложены как две независимые оси.

Первый рынок — Великобритания, 9 языков перевода. Архитектура рассчитана на добавление новых стран без релиза приложения.

Статус: **планирование**. Кода пока нет — сначала утверждается план.

## Три вещи, которые важнее остального

1. **Лицензия DVSA блокирует релиз, а не разработку.** Заявка подаётся в первую неделю, разработка идёт на демо-банке. Публиковать вопросы DVSA без договора — уголовное правонарушение.
2. **Страна и язык — независимые оси.** Если добавление Ирландии потребует правок в коде приложения, архитектура сделана неправильно.
3. **Аккаунтов нет.** Прогресс живёт на устройстве, подписка возвращается через Restore Purchase.
