# План работ

Оценка дана в неделях для состава «один мобильный разработчик + один фулстек на бэкенд и админку + дизайнер на part-time». При двух мобильных разработчиках фазы 2–4 сжимаются примерно на треть.

**Главная зависимость:** дата релиза определяется не готовностью кода, а получением лицензии DVSA (Р-1). Код будет готов к неделе 12; если лицензии к этому моменту нет, релиз ждёт её.

---

## Фаза 0. Подготовка — неделя 1

Идёт параллельно с чем угодно, но начинается первой.

- [ ] **Подать заявку на лицензию DVSA** — сразу foreign language product licence (OQ-1)
- [ ] Проверить занятость названия «RoadReady» в сторах и по товарным знакам (OQ-4)
- [ ] Завести аккаунты App Store Connect и Google Play, если их нет (OQ-6)
- [ ] Репозиторий, CI-сборки, окружения dev / prod
- [ ] Проект Firebase, правила доступа Firestore
- [ ] Дизайн: исправления контраста, тёмная палитра, шесть недостающих экранов (раздел 6 в [04-design-system.md](04-design-system.md))
- [ ] **Технический спайк, 1–2 дня** — до написания продуктового кода:
  - dev-build на SDK 57 с New Architecture, покупка в песочнице через Adapty (Р-12)
  - проверка Google Play Billing 8 в собранном APK (Р-11) — это условие публикации
  - config-плагин исключения из бэкапа, флаг переживает запись файлов (Р-13)
  - латентность чтения времени видео на бюджетном Android — до фиксации порогов hazard perception
  - Amplitude под New Architecture

**Готово, когда:** заявка подана, репозиторий собирается, спайк подтвердил стек или вскрыл замену, дизайнер работает по правкам.

## Фаза 1. Фундамент — недели 2–3

- [ ] Скелет приложения: навигация по [05-screens-map.md](05-screens-map.md), вкладки, модальные экраны
- [ ] Система тем: токены, светлая и тёмная, переключение по системной настройке
- [ ] Базовые компоненты: кнопки, карточки, индикаторы, `BilingualText`, `AnswerOption`, `TopicNode`
- [ ] Локальная БД и схема прогресса
- [ ] Слой контента: чанкованная загрузка пакета с возобновлением после перезапуска, распаковка, версии, доступ к вопросам
- [ ] Config-плагин исключения контент-пакета из бэкапа, база прогресса в бэкапе остаётся (Р-13)
- [ ] Демо-пакет: ~50 вопросов, знаки OGL, переводы на 2 языка (OQ-5)
- [ ] Экраны онбординга: Splash, Welcome, Country, Language, Goal

**Готово, когда:** приложение на устройстве проходит онбординг, скачивает демо-пакет и показывает первый вопрос на двух языках.

## Фаза 2. Обучение — недели 4–6

- [ ] Карта тем: состояния узлов, последовательная разблокировка, декор
- [ ] Экран темы: прогресс, список уроков, точность, слабейшая подтема
- [ ] Карточный сценарий урока: 5 вопросов, изображения, озвучка
- [ ] Обратная связь: верный и неверный ответы, пояснение на двух языках, «+10 XP»
- [ ] Экран завершения урока: счёт, XP, серия, «Perfect score»
- [ ] Механика прогресса: XP, серия, дневная цель, mastered, очередь повторения
- [ ] Dashboard: приветствие, серия с календарём, «Continue Learning», кольцо цели, обратный отсчёт
- [ ] Озвучка: кнопка на каждой карточке, скорость, автозапуск. Воспроизведение предгенерированных файлов из пакета, системный TTS — фолбэк (ADR-010)

**Готово, когда:** полный цикл «Dashboard → урок → обратная связь → завершение → обновлённый прогресс» работает на реальных данных, серия и XP считаются корректно между запусками.

---

## Фаза 3. Практика — недели 7–8

- [ ] Mock Test: настройка, 50 вопросов, таймер, флажки, навигация вперёд-назад
- [ ] Проверка перед отправкой: сетка статусов, переход к вопросу
- [ ] Результаты: вердикт, точность по темам, список ошибок, разбор
- [ ] Quick Quiz: 10 случайных вопросов, итоговая сводка
- [ ] Weak Spots: адаптивная очередь по ошибкам
- [ ] Hazard Perception: плеер, замер времени реакции, оценка — **за фича-флагом** (ADR-006)

**Готово, когда:** mock-тест проходится целиком, результат и разбор ошибок совпадают с ответами; таймер корректно ведёт себя при сворачивании приложения.

## Фаза 4. Профиль, настройки, подписка — недели 9–10

- [ ] Profile: метрики, достижения, обратный отсчёт
- [ ] Достижения: условия, выдача, всплывающая карточка
- [ ] Settings по [05-screens-map.md](05-screens-map.md), без секции аккаунта
- [ ] Смена страны и языка из настроек, без перезагрузки основного контента
- [ ] Управление офлайн-контентом: загрузка, размер, удаление
- [ ] Подписка: пейволл, триал, покупка, восстановление, экран окончания триала, лимиты Free
- [ ] Уведомления: ежедневное напоминание, «Вопрос дня» с переходом по deep link

**Готово, когда:** покупка и восстановление проходят в песочнице на обеих платформах, лимиты Free применяются во всех точках.

## Фаза 5. Бэкенд и админка — недели 3–9, параллельно

- [ ] Модель данных в Firestore, правила доступа, роли
- [ ] Cloud Function сборки и публикации пакета, расчёт `versionHash`, валидация перед публикацией
- [ ] Админка: CRUD стран, тест-сеты, публикация и архивация
- [ ] Импорт из CSV/Excel с построчным отчётом об ошибках
- [ ] Редактор переводов и панель статусов по языкам (FR-15)
- [ ] Медиатека: загрузка, привязка к вопросам, тип лицензии, защита от удаления используемых файлов
- [ ] Soft delete во всех сущностях (FR-16)
- [ ] Вебхуки биллинга

**Готово, когда:** контент-редактор без участия разработчика заливает новый тест-сет из Excel, переводит его и публикует, а приложение получает обновление без релиза.

## Фаза 6. Контент и переводы — недели 4–12, параллельно

- [ ] Глоссарий ~200 терминов, вычитка носителями
- [ ] Машинный перевод демо-банка на все 9 языков, отладка пайплайна
- [ ] **После получения лицензии:** импорт 730 вопросов и медиа
- [ ] Машинный перевод полного банка на 9 языков
- [ ] Полная вычитка приоритетных языков (OQ-2)
- [ ] Генерация аудио-озвучки английских вопросов и включение её в пакет (ADR-010)
- [ ] Проверка RTL на арабском и урду на всех экранах

**Готово, когда:** опубликован тест-сет UK-2026 со всеми языками и корректными статусами переводов.

---

## Фаза 7. Полировка и приёмка — недели 11–12

- [ ] Тёмная тема на всех экранах
- [ ] VoiceOver и TalkBack: проход по всем экранам
- [ ] Масштабирование шрифта, экраны от 360 dp до iPhone 16 Pro Max
- [ ] Офлайн-сценарии: первый запуск без сети, обрыв загрузки, работа без сети
- [ ] Производительность: холодный старт ≤ 2 с, размер сборки ≤ 300 МБ
- [ ] Аналитика: события воронки, проверка в Amplitude
- [ ] Пустые состояния, ошибки, состояния загрузки
- [ ] Юридические тексты: Crown Copyright, OGL, Privacy Policy, Terms (OQ-7)
- [ ] Регрессионный прогон на обеих платформах

**Готово, когда:** чек-лист из раздела 5 в [05-screens-map.md](05-screens-map.md) пройден по каждому экрану на обеих платформах.
