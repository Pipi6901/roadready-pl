# Монетизация

## 1. Модель

Подписка с трёхдневным пробным периодом. Разовой покупки нет.

Обоснование из ТЗ 2.4: продукт построен на регулярном взаимодействии (серия, ежедневная цель, адаптивный повтор), поэтому продаётся продолжающаяся ценность, а не разовый доступ к банку вопросов. Рыночный диапазон — £3.99–5.99 за разовую покупку либо ≈£4.99/мес за подписку.

| Тариф | Цена | Примечание |
|---|---|---|
| Monthly | £4.99 | базовый |
| Yearly | £39.99 | экономия 33%, выгоднее в пересчёте на месяц |
| Trial | 3 дня бесплатно | один раз на аккаунт стора |

Для Google Play заводится зеркальный набор SKU с той же ценовой логикой. Отображение цен и периодов — через данные стора, а не хардкодом: локаль и валюта берутся из устройства (ТЗ 11).

---

## 2. Экономика одной подписки

На £4.99 накладываются три вычета:

| Статья | Доля |
|---|---|
| Комиссия стора | 30%, после года подписки — 15% |
| Роялти DVSA | 13% от net sales |
| Слой биллинга | процент от выручки сверх бесплатного порога |

То есть с £4.99 до проекта доходит ориентировочно £2.8–3.2 в первый год подписчика. Это нужно учитывать в юнит-экономике: стоимость привлечения должна считаться от этой цифры, а не от £4.99.

---

## 3. Бесплатный тариф

Полная блокировка после триала запрещена требованием FR-13 — приложение должно ограничивать функциональность, а не отключаться.

| Возможность | Free | Pro |
|---|---|---|
| Вопросов в день | 10 | без ограничений |
| Перевод на выбранный язык | нет | есть |
| Mock Test | нет | есть |
| Quick Quiz | есть | есть |
| Weak Spots | нет | есть |
| Hazard Perception | нет | есть (после ADR-006) |
| Офлайн-режим | нет | есть |
| XP, серия, статистика | есть | есть |

Отсутствие перевода на бесплатном тарифе — сознательное решение: перевод и есть ключевая ценность продукта и главный повод платить.

---

## 4. Точки показа пейволла

1. **Онбординг** — последний шаг, после выбора даты экзамена. Закрывается крестиком, пользователь попадает на Home с ограничениями Free (ТЗ 3.6).
2. **Окончание триала** — отдельный экран со сравнением Free и Pro (ТЗ 8.4).
3. **Упор в лимит** — при попытке открыть 11-й вопрос за день, Mock Test, Weak Spots или включить перевод.
4. **Настройки** — раздел «Подписка».

Ограничение: не показывать пейволл дважды за сессию и не прерывать им незавершённый урок — иначе растёт число удалений приложения.

---

## 5. Требования Apple и Google

Пейволл обязан явно показывать (NFR-12, ТЗ 3.6):
- стоимость и период оплаты;
- длительность пробного периода и то, что по его окончании списание происходит автоматически;
- возможность отмены в любой момент;
- ссылки на Условия использования и Политику конфиденциальности;
- кнопку «Restore Purchase» — при отсутствии аккаунтов (ADR-002) это единственный способ вернуть подписку после переустановки, поэтому она обязана быть и на пейволле, и в настройках, и на экране Welcome.

Подписочные приложения проходят усиленную проверку App Review — экран пейволла и восстановление покупок проверяются в первую очередь.

---

## 6. Что нужно завести до релиза

**App Store Connect:** группа подписок, два продукта (monthly, yearly), 3-дневный вводный оффер на оба, локализованные названия и описания, скриншот пейволла для ревью, ценовая матрица по территориям.

**Google Play Console:** подписка с двумя базовыми планами, оффер бесплатного пробного периода, зеркальные цены.

**Слой биллинга:** приложения обеих платформ, продукты, сопоставление с правами доступа (`pro`), вебхуки на Cloud Function для отслеживания статусов, песочница для тестирования.

**Тестовые сценарии:** покупка, отмена во время триала, истечение триала, восстановление после переустановки, отказ платежа, апгрейд с месячной на годовую, оплата в офлайне и последующая синхронизация.

## 7. Аналитика

Amplitude, ключевые события воронки:

```
onboarding_started / country_selected / language_selected / goal_set
paywall_shown        { source, plan_default }
trial_started        { plan }
paywall_dismissed    { source }
purchase_completed   { plan, price, currency }
purchase_restored
trial_expired
lesson_started / lesson_completed   { topic_id, correct, xp }
mock_test_started / mock_test_finished { score, passed }
limit_hit            { limit_type }
content_download_started / finished  { size_mb, duration_ms }
streak_continued / streak_broken
```

Обязательные метрики к первому месяцу: конверсия онбординга в триал, триала в платную подписку, удержание D1/D7/D30, доля дошедших до первого завершённого урока, доля упирающихся в дневной лимит.
