# Объём MVP — RoadReady

Рабочее название из макета — **RoadReady**. Слоган: «Pass your driving theory test — in your language».

Документ уточняет ТЗ (`черновик ТЗ.md`, `экранные формы.md`) с учётом решений в [00-decisions.md](00-decisions.md). Где текст ниже расходится с исходным ТЗ, приоритет у этого документа — расхождения перечислены в конце явно.

---

## 1. Что делаем

Приложение для подготовки к экзамену по теории вождения. Формат подачи — Duolingo: короткие уроки по 5 вопросов, мгновенная обратная связь, XP, серия дней, последовательная разблокировка тем.

Отличие от конкурентов в App Store — **две независимые оси: страна и язык перевода**. Вопрос показывается на английском, под ним перевод на выбранный пользователем язык. Ни у одного из шести разобранных UK-конкурентов такого нет (ТЗ 2.2).

В MVP контентно наполнена одна страна — Великобритания. Мультистрановость реализуется архитектурно с первого дня: добавление Ирландии не должно требовать ни строчки нового кода.

## 2. Состав первого релиза

### Контент
- 1 страна: Великобритания. До получения лицензии — демо-банк ~50 вопросов (ADR-007), после — лицензионный пакет DVSA: 730 вопросов, 14 тем, изображения, пояснения.
- 9 языков перевода поверх английского: польский, урду, панджаби, хинди, испанский, испанский (LatAm), португальский, португальский (BR), арабский. Плюс режим «English only».
- Интерфейс приложения — только английский (ТЗ 10.5).

### Функциональность
| Блок | Состав |
|---|---|
| Онбординг | Splash → Welcome → выбор страны → выбор языка → дата экзамена → пейволл → Home |
| Обучение | Карта тем с последовательной разблокировкой, экран темы, уроки по 5 вопросов, обратная связь с пояснением на двух языках, экран завершения урока |
| Практика | Mock Test (50 вопросов / 57 минут / проходной 43), Quick Quiz (10 случайных), Weak Spots (адаптивный повтор ошибок) |

## 3. Что сознательно не входит

Из ТЗ 5.2 плюс уточнения по итогам решений:

- Другие страны кроме UK — архитектура готова, контента нет.
- Аккаунты, вход, кросс-девайс-синхронизация прогресса (ADR-002).
- Hazard Perception — код есть, включается флагом после получения контента (ADR-006).
- Лидерборды, лиги, мини-игры, флэшкарты, любой социальный слой.
- Краудсорс-правки переводов.
- Живая (не системная) озвучка.
- Pass Guarantee, B2B-канал через автошколы, доступ для инструкторов.
- Локализация интерфейса приложения (интерфейс английский; переводится только учебный контент).

## 4. Правила продуктовой механики

Зафиксировано, чтобы разработка и дизайн не расходились:

**Урок** — ровно 5 вопросов. Тема состоит из уроков, число уроков = ⌈вопросов в теме / 5⌉.

**XP** — 10 за верный ответ с первой попытки. Урок из 5 верных = 50 XP. Экран завершения урока показывает XP за урок, а не накопленный.

**Дневная цель** — 3 урока в день. Серия засчитывается при выполнении цели; пропущенный день серию обнуляет.

**Разблокировка** — тема открывается после завершения предыдущей. Первая тема открыта всегда (ТЗ 5.1, FR-11).

**Освоенный вопрос (mastered)** — два верных ответа подряд в разных сессиях. Ошибка снимает статус и возвращает вопрос в очередь повторения.

**Адаптивный повтор** — вопрос с ошибкой попадает в очередь Weak Spots и подмешивается в следующие уроки (FR-10). Приоритет — по числу ошибок и давности.

**Готовность к экзамену (%)** — доля освоенных вопросов от общего числа в стране. Показывается на Dashboard и в Profile рядом с обратным отсчётом.

**Mock Test** — 50 случайных вопросов пропорционально по темам, таймер 57 минут, проходной 43. Правильность до отправки не показывается.

### Ограничения бесплатного тарифа
После окончания триала (ТЗ 8.4, FR-13) — не блокируем полностью, а ограничиваем:

| Возможность | Free | Pro |
|---|---|---|
| Вопросов в день | 10 | без ограничений |
| Перевод на выбранный язык | нет, только английский | есть |
| Mock Test | нет | есть |
| Quick Quiz | есть | есть |
| Weak Spots | нет | есть |
| Hazard Perception | нет | есть (после ADR-006) |
| Офлайн-режим | нет | есть |
