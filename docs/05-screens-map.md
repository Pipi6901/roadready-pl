# Карта экранов и навигация

Источники: макет `screens.pen` (24 фрейма, 375×812), экранные формы ТЗ (разделы 3–8), HTML-прототип `~/Desktop/driving-theory-wireframe/index.html` — в нём уже реализована логика переходов и состояний, используем как референс поведения.

Навигация — Expo Router (файловый роутинг).

│
├── quiz.tsx                        Quick Quiz
├── weak-spots.tsx                  адаптивный повтор ошибок

Панель вкладок скрывается на уроке, mock-тесте, quick quiz, weak spots и hazard-клипе (ТЗ 10.1).

## 3. Схема переходов

**Первый запуск:** Splash → Welcome → Country → Language → Goal → Paywall → Home

**Повторный запуск:** Splash → Home (либо напрямую на экран из deep link)

| Раздел | Последовательность |
|---|---|
| Главная | Dashboard → Continue → урок → обратная связь → Lesson Complete |
| Обучение | Topic List → Topic Detail → урок → обратная связь → Lesson Complete |
| Практика | Practice Hub → Mock / Quick Quiz / Hazard / Weak Spots |
| Mock-тест | Setup → вопросы → Review → Results → разбор ошибок или повтор |
| Профиль | Profile → Settings → подписка / смена страны / смена языка |

Возврат из модального окна — всегда на экран, из которого оно открыто (ТЗ 10.1).

## 4. Переиспользуемые компоненты

Из макета уже вынесены как reusable: `TabBar`, `Topic Node`, `Answer Option`.

Полный список для библиотеки компонентов:

- `TabBar` — нижняя панель, 4 вкладки
- `TopicNode` — узел карты тем: заблокирован / доступен / текущий / завершён
- `AnswerOption` — карточка ответа: обычная / выбранная / верная / неверная / отключённая
- `BilingualText` — английский основным, перевод ниже вторичным (ТЗ 10.3, 10.4). Единственный разрешённый способ показа двух языков; две колонки запрещены
- `ProgressBar`, `ProgressRing` — линейный и круговой индикаторы
- `StatTile` — метрика с иконкой (XP, серия, точность, освоено)
- `TopicCard`, `LessonRow`, `PracticeCard`, `SettingsRow`, `SettingsSection`
- `CountdownCard` — обратный отсчёт до экзамена и % готовности
- `StreakCalendar` — 7 индикаторов дней
- `AchievementBadge` — получено / заблокировано
- `SpeakButton` — озвучка вопроса, обязательна на каждой карточке (ТЗ 10.8)
- `FeedbackSheet` — выдвижная панель обратной связи, верная и неверная
- `OfflineBanner`, `PrimaryButton`, `SecondaryButton`, `FlagIcon`

## 5. Проверки для каждого экрана

Прогоняется на обеих платформах перед приёмкой:

1. Светлая и тёмная тема, контраст сохраняется в обеих (ТЗ 10.7).
2. VoiceOver и TalkBack: у всех интерактивных элементов есть подписи, состояние не передаётся только цветом (ТЗ 10.8).
3. Системное увеличение шрифта не обрезает значимый текст.
4. Экраны от 360 dp (Android) и iPhone SE 3 до iPhone 16 Pro Max (NFR-09).
5. Зоны нажатия не меньше 44 pt.
6. Поведение офлайн: экран работает на загруженном контенте, показан баннер.
7. Free и Pro: ограничения тарифа применяются корректно.
8. Аппаратная кнопка «назад» на Android ведёт себя как экранная.
