# Статус реализации

Обновлено 2026-07-20. Приложение запускается, проходится насквозь и проверено в браузере (Expo web) на светлой и тёмной теме.

---

## Что готово

**Инфраструктура.** Expo SDK 57 (RN 0.86, New Architecture), expo-router с типизированными маршрутами, TypeScript strict — `npm run typecheck` зелёный.

**Тема.** Токены из макета один в один, тёмная палитра выведена и проверена по контрасту. Хардкод-цветов в компонентах нет. Переключение по системной настройке.

**Данные.** Демо-банк: 48 собственных вопросов по Highway Code, 14 тем, полные переводы на испанский и польский, равномерное распределение верных ответов (A/B/C/D по 12). Формат совпадает с форматом импорта лицензионного пакета DVSA.

**Экраны — 31 маршрут:**

| Группа | Экраны |
|---|---|
| Онбординг | Splash, Welcome, Country, Language, Goal, Paywall |
| Вкладки | Dashboard, Topic List (карта-маршрут), Practice Hub, Profile |
| Обучение | Topic Detail, карточный сценарий урока, обратная связь, Lesson Complete |
| Практика | Mock Setup / Run / Review / Results, Quick Quiz, Weak Spots, Hazard (за флагом) |
| Настройки | Settings, Управление подпиской |
| Модалки | Смена страны, смена языка, окончание триала, достижение |

**Механики.** XP, серия по дневной цели, mastered (два верных подряд), очередь повторения, последовательная разблокировка тем, точность по темам, слабейшая подтема, достижения, лимиты бесплатного тарифа, таймер mock-теста от абсолютной метки (переживает сворачивание приложения).

**Проверено вживую:** онбординг целиком, двуязычный режим (английский сверху, испанский под ним), обратная связь с начислением XP, карта тем, практика, профиль, тёмная тема.

## Отклонения от макета (осознанные)

1. Экран регистрации и секция ACCOUNT удалены, вместо них Restore Purchase и Reset progress (ADR-002).
2. Hazard Perception убран с пейволла, карточка в практике — «Coming soon» (ADR-006).
3. Дневная цель считается в уроках, а не в XP — по продуктовому правилу, а не по картинке.
4. Фейковый статус-бар макета заменён на настоящий SafeArea.
5. Флаги — эмодзи вместо векторных фигур: иначе каждая новая страна требует ручной отрисовки.
6. Юридический текст без упоминания Crown Copyright — до подписания лицензии такая атрибуция некорректна.
7. Мелкий зелёный текст берёт `successText` вместо `successDark`: последний даёт 3.0:1 на светлом фоне и проваливает WCAG AA.
8. Добавлен токен `onSurfaceAlt` — цвет иконок и букв на sage-поверхностях. Без него в тёмной теме буквы вариантов ответа были нечитаемы.

## Что осталось

**Требует решений или контента**
- Каталог hazard-клипов пуст — ждёт лицензионный пакет.
- Цены на пейволле — константы; в проде приходят из стора.
- Terms of Service и Privacy Policy — заглушки, нужны реальные URL (OQ-7).
- Пикеры даты экзамена и времени напоминания — заглушки с TODO.
- Кнопка Subscribe на экране окончания триала ждёт биллинг-модуль.

**Технический долг**
- `restore()` в провайдере подписки — заглушка до спайка Adapty (ADR-005).
- Прогресс хранится в AsyncStorage; по архитектуре должен переехать в SQLite. Интерфейс репозитория узкий, замена локальна.
- Два разных компонента карточки ответа (`learning/AnswerOptionCard` и `practice/AnswerOption`) реализуют один элемент макета — свести к одному.
- Флаг вопроса в уроке живёт только в локальном состоянии, в прогрессе нет API для отмеченных.
- «Continue to next lesson» не переходит к следующей теме, когда текущая пройдена.
- Переигрывание завершённого урока не поддержано.
- Загрузка контент-пакета, config-плагин исключения из бэкапа, предгенерация аудио — фаза 1 по плану, пока приложение работает на встроенном демо-банке.

**Не начато**
- Бэкенд и админка (фаза 5 плана).
- Аналитика Amplitude, уведомления, «Вопрос дня».
- Реальный биллинг.

## Как запустить

```
npm start          # дев-сервер Expo
npm run typecheck  # проверка типов
```

Для проверки в браузере: `npx expo start --web`. Хранилище чистится через `localStorage.clear()`.

**Важно:** в вебе RN-Web реагирует на pointer-события; синтетические клики без них до Pressable не доходят — это особенность проверки, а не приложения.
